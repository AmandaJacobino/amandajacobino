# Amanda Jacobino — Portfólio

Portfólio pessoal desenvolvido com React, TypeScript e Tailwind CSS. Design minimalista em preto e branco com animações suaves via Framer Motion.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite 5**
- **Tailwind CSS 3**
- **Framer Motion 11**
- **Lucide React**

## Seções

| Seção | Descrição |
|---|---|
| Navbar | Navegação com links de seções e CTA para WhatsApp |
| Hero | Apresentação com lista de tecnologias animada |
| Projects | Projetos reais com links para GitHub e live |
| Services | Serviços oferecidos |
| About | Bio e foto |
| Contact | Links de contato (LinkedIn, GitHub, WhatsApp, E-mail) |
| Footer | Rodapé |

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Estrutura

```
src/
├── components/    # Seções da página
├── data/          # Dados de projetos e serviços
└── hooks/         # useScrollReveal
public/
└── images/        # Fotos e screenshots dos projetos
```
